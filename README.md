# Cờ Vua

Chơi với máy (3 mức độ) hoặc 2 người trên cùng một thiết bị. Chạy hoàn toàn trên trình duyệt, không cần server.

## Chạy
Mở file `index.html` bằng trình duyệt, hoặc đưa cả thư mục lên GitHub Pages.

## Cách dùng
- Nút ⚙ (góc trên bên phải): đổi chế độ, phe, độ khó, đồng hồ, màu bàn cờ.
- Dưới bàn cờ: Ván mới, Đi lại, Gợi ý, Xoay bàn cờ, Âm thanh.
- Mục "Thế cờ (FEN)": sao chép hoặc nạp thế cờ.
